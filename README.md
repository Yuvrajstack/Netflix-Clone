A simple static front-end clone of Netflix, built using HTML, CSS, and JavaScript. This project replicates the basic UI of the Netflix homepage, complete with a banner, thumbnails, and responsive layout.

## Overview

The goal of this project is to practice and demonstrate front-end web development skills by recreating a popular UI. It is designed for educational purposes and does not contain any backend or streaming functionality.

### Features

- Clean and responsive UI
- Hero banner with call-to-action
- Row-based sections for different categories
- Hover effects and smooth scrolling
- Mobile-friendly design

## Tech Stack

- *HTML5* for structure
- *CSS3* for styling and layout
- *JavaScript (optional)* for interactivity (if added)
